Usage: {% include post-thumb.html post=post %} Callers render it as a CSS background, never an : Chirpy's refactor-content wraps every in a lightbox , which would nest an anchor inside the card links these thumbnails live in. {% endcomment %} {% assign thumb_src = '' %} {% if include.post.image %} {% assign thumb_src = include.post.image.path | default: include.post.image %} {% if include.post.media_subpath %} {% unless thumb_src contains '://' %} {% assign thumb_src = include.post.media_subpath | append: '/' | append: thumb_src | replace: '///', '/' | replace: '//', '/' %} {% endunless %} {% endif %} {% endif %}
