{% comment %} Shared writeup statistics, computed once from the posts so every number on the site stays in sync. Used by the Machines dashboard (_layouts/machines.html) and the home landing (_layouts/home.html). Assigns into the caller's scope: ws_posts visible writeups: pinned first, then newest first ws_total how many there are ws_levels the difficulty categories, easiest first ws_os_levels the OS tags a writeup can carry (its "system") ws_platforms every other category (HackTheBox, TryHackMe, …), sorted ws_cve_count distinct CVE ids across all writeup tags ws_topic_count distinct technique / tool tags (CVE ids and OS tags aside) ws_year the build year; ws_year_count = writeups dated in it ws_spark cumulative writeup count at the end of each of the last 12 months, oldest first ws_spark_keys those months as YYYYMM numbers (same order) {% endcomment %} {% assign ws_pinned = site.posts | where_exp: 'item', 'item.pin == true and item.hidden != true' %} {% assign ws_normal = site.posts |
